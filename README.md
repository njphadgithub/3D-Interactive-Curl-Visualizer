# 3D Interactive Curl Visualizer

An advanced, self-contained educational web application created by **Dr. Nitin Phadkule** (Govt. College of Engineering, Chh. Sambhajinagar) to interactively explore and visualize the **Curl of a Vector Field** ($\nabla \times \mathbf{H}$) in three-dimensional space.

### Key Features:

* **True 3D Native Engine:** Full mouse orbit rotation, zooming, and camera presets (Top, Isometric, Side View).
* **Microscopic Vorticity:** Visualize how vector fields induce rotation and spin across spatial points using animated 3D paddlewheels.
* **Interactive Parameters:** Adjust field components and coefficients ($a, b$) in real time.
* **Step-by-Step Guide:** Interactive tutorial panel breaking down vector fields, curl operators, and physical analogies.
* **MathJax Integration:** Professional mathematical typesetting for vector calculus formulas.
* **100% Offline-Ready:** Single HTML file implementation with zero external dependencies.

### How to Use:

Download `curl3d.html`, open it in any modern web browser, adjust the vector coefficients via interactive sliders, and explore fluid and field rotation dynamics in 3D!
